# ADR 0001: Record architecture decisions

Status: Accepted (2026-11-07)

## Decision

We record significant decisions as short ADRs in docs/adr, numbered and never edited after acceptance (supersede instead).

## Why

Decisions taken in docs/plan are traceable; new contributors read why, not only what.

## Consequences

- Template: Context, Decision, Consequences, Status.
- Plan docs link to ADRs; ADRs link to backlog IDs.
